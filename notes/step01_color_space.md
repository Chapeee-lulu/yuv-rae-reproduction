# 第1步笔记：RGB与YUV 4:4:4转换

## 本步要回答的问题

1. Y、U、V各自表示什么？
2. 为什么论文选择在Y通道攻击、在U/V通道嵌入？
3. 浮点RGB→YUV→RGB是否近似可逆？
4. 中间结果取整后，是否仍然逐像素完全一致？
5. 如果颜色转换本身产生±1误差，论文所说的“error-free recovery”需要额外保证什么？

## 论文公式

正向转换：

```text
Y =  0.2990R + 0.5870G + 0.1140B
U = -0.1687R - 0.3313G + 0.5000B + 128
V =  0.5000R - 0.4187G - 0.0813B + 128
```

反向转换：

```text
R = Y + 1.402(V - 128)
G = Y - 0.34414(U - 128) - 0.71414(V - 128)
B = Y + 1.772(U - 128)
```

## 本步实验逻辑

- 实验目标：验证仅使用论文公式并进行整数取整，能否保证RGB逐像素无损往返。
- 实验设计：读取一张PNG，转换为YUV，再转换回RGB；比较原图和恢复图的每个通道。
- 实验数据：由脚本直接输出最大误差、平均误差、变化像素数和变化比例。
- 数据解析：只有所有通道的误差均为0，才能称为逐像素完全一致。

## 重要区分

“YUV 4:4:4没有色度下采样”不自动等于“整数矩阵转换逐像素可逆”。

- 4:4:4表示Y、U、V三个通道具有相同空间分辨率。
- 浮点矩阵变换可以非常接近可逆。
- 一旦中间进行整数取整，就可能出现量化误差。

## 第一张图的初步观察

使用官方数据中的`0001_321.png`进行独立验证：

- 图像尺寸：299×299；
- 浮点往返最大绝对误差约0.00948；
- 中间YUV取整后，RGB往返最大绝对误差为1；
- 64851/89401个像素至少有一个通道变化，占72.54%；
- 因此，论文公式配合普通整数取整本身不能直接证明RGB逐像素无损。

这只是待解释的复现发现，不能直接据此判定论文结论错误。下一步需要明确：

1. 论文的“error-free”是相对哪个中间表示定义的；
2. PEE恢复的是YUV载体还是原始RGB；
3. 作者实验是否做了RGB逐像素相等验证，还是只报告SSIM=1.000。
